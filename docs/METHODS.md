# 手法（METHODS）

東京23区・中古マンションの平米単価（万円/㎡）を、時空間ラグ（ST-lag）と
勾配ブースティング／グラフニューラルネット（GNN）で予測するパイプラインの手法書。
**リーク無し評価**を生命線とし、単年の一発R²ではなく「複数四半期にわたる分布
（平均±標準偏差）」で正直に報告する。数値は本リポジトリの実コード出力で裏取りしている
（`outputs/*.csv`、64四半期フォールド = 2010Q1〜2025Q4）。

---

## 1. データ

- **出所**: 国土交通省「不動産情報ライブラリ」サイト版CSV（種類=中古マンション等／用途=住宅）。
  最寄駅情報がサイト版にのみ含まれるためこれを正本とする（`config.SOURCE_CSV`, cp932）。
  町丁目境界は e-Stat（令和2年 国勢調査 東京都 町丁目 shapefile, `r2ka13.shp`）。
- **対象・規模**: 東京23区。`tokyo23_model_table_q.csv` で目的変数が有効なレコード
  **216,569件**、取引時期 **2005Q3〜2025Q4**。データに出現する町丁目 **857町**、最寄駅 **477駅**。
- **四半期化**: 「取引時期（例: 2025年第1四半期）」から四半期通し番号
  `Qidx = Year*4 + (Quarter-1)` を作る（`02_features.py`）。S-lag/T-lag・Expanding Window CV は
  この `Qidx` を時間軸に使う。
- **クレンジング（決定論的, 02）**: 価格0や面積欠損など「あり得ない／計算不能」を除去。
  統計的な外れ値処理（IQR）はここでは行わず、評価時の訓練フォールド内のみで行う（§4）。

## 2. 特徴量

| 区分 | 特徴量 | 役割 |
|------|--------|------|
| 物件 | `Age`(築年数), `Area_num`(面積), `Rooms`(間取り室数), `Is_RC`, `Is_Renovated`, `FAR_CAR_ratio`(容積率/建蔽率) | 物件固有の価格規定要因 |
| 立地（駅） | `Station_min`(最寄駅 徒歩分) | 駅近接性。寄与は小さい（ΔR²≈ −0.004） |
| 立地（駅） | `Station_TE`(最寄駅名のターゲットエンコーディング) | 駅の価格水準。`Station_min` とは別形態。冗長気味（ΔR²≈ −0.004） |
| 立地（区/用途） | `Municipality`(区), `Zoning`(都市計画/用途地域) | one-hot。Zoning は冗長（ΔR²≈ −0.0005） |
| 空間 | `centroid_x`, `centroid_y`(町重心, EPSG:6677) | 位置。GNNのノード特徴にも使う |
| 時間ラグ T-lag | `Lag_q1_AvgPrice`(直前1Q), `Lag_q4_AvgPrice`(前年同期=4Q前) | 自町の過去平均単価 |
| 空間ラグ S-lag | `S_Lag_q1_AvgPrice`, `S_Lag_q4_AvgPrice` | 近隣町の過去平均単価 |

**駅の2形態**: 物件単位の「徒歩分（`Station_min`）」と、駅名の「ターゲットエンコーディング
（`Station_TE`）」。後者は目的変数を使うため**各フォールドの訓練のみで fit**（§4, `lib_features.StationTargetEncoder`、
平滑化 m=50）。アブレーション上はどちらも寄与が小さく、両者はやや冗長（§6）。

## 3. ST-lag の生成（過去のみ参照）

- **T-lag（時間ラグ, 03q）**: 各町×四半期について、**暦ベース結合**で直前四半期（`Qidx−1`）と
  前年同期（`Qidx−4`）の自町平均単価を引く。pandas の `shift` は使わず暦結合するため、
  欠四半期は誤参照されず **NaN** になる。参照は厳密に過去のみ。
- **S-lag（空間ラグ, 04q）**: 23区の町丁目を**一括で** queen 隣接（区境をまたぐ）にし
  （`lib_spatial.build_neighbors`）、近隣町の T-lag を平均して `S_Lag_*` を作る。
  旧コードの「区ごとに閉じて隣接を計算（区境の町が隣区を取りこぼす）」欠陥を解消している。

既定のラグ構成は **Qboth**（直前1Q + 前年同期、それぞれ T-lag/S-lag の4列）。
05q の比較で Qboth が最良（全体XGB R²: Qprev 0.557 / Qyoy 0.531 / **Qboth 0.574**）であり、
08q アブレーションや時空間GNN等の下流はこれを参照する（`config.DEFAULT_LAG_*`）。

## 4. リーク無し Expanding Window CV（64四半期）

各テスト四半期 `q` について「`Qidx < q` を訓練 / `Qidx == q` をテスト」で1モデルを学習し、
全体・区別・サブグループ別のR²を**予測の事後スライス**で出す（`lib_eval.expanding_window_pooled`,
`time_col="Qidx"`）。検証四半期は 2010Q1〜2025Q4 の **64四半期**（`EXPANDING_TEST_QUARTERS`）。

主指標は `r2`（テストを一切トリミングしない正直な値）。併記の `r2_trim` は、訓練由来の
IQR閾値をテストにも当てた感度分析値。

**旧コードからの3欠陥是正**（議事録対応）:
1. **隣接の取りこぼし** … 区ごとに閉じた隣接 → 23区一括 queen 隣接（区境をまたぐ, §3）。
2. **時間プーリング** … 全期間を混ぜた学習・評価 → Expanding Window（テストは厳密に未来）。
3. **外れ値リーク** … 全データでIQR → **訓練フォールドの分布のみ**で閾値決定し訓練側だけトリミング
   （`trim_by_iqr`, 区ごと k=1.5）。標準化器・駅TE・OneHotEncoder も**各フォールドの訓練のみで fit**。

## 5. モデル

全モデルを**同一の64四半期フォールド**で評価する統合ハーネス `run_compare.py`
（学習・評価ロジックは `src/lib_compare.py` に集約）。出力は tidy な1表
`outputs/results_long.csv`（`model, scope, name, r2_mean, r2_std, r2_min, r2_max, n_folds`）。

- **OLS**: 線形ベースライン（Base + Qboth + 駅TE + 区/用途 one-hot）。
- **XGBoost**:
  - `XGB-propT` … 物件特徴 + 自町T-lag のみ（S-lag・駅TE・one-hot 無し ＝ GNNと同程度の情報）。
  - `XGB-full(Qboth)` … Base + Qboth(T+S-lag) + 駅TE + 区/用途 one-hot（強いベースライン）。
- **GNN（時空間, PyTorch Geometric）**:
  - `GNN-min`（静的GCN v0, 09）… 町丁目 queen 隣接に2層GCN。各四半期スナップショットの
    「自町ラグ＋重心」をノード特徴に空間伝播し、町表現を物件特徴と結合して回帰。
    手作りS-lag（近隣平均）を**グラフ伝播**に置き換えられるかを見る。
  - `GNN-temporal`（GCN+時間集約, 10）… 各町の直近 **L=8** 四半期の観測平米単価系列
    （前方補完＋観測フラグ＋重心）を、各時点GCN（重み共有）で空間伝播 → **時間集約器**で1つの
    町表現に畳む。系列は厳密に過去のみ `seq_steps = [q−L, …, q−1]`。
- **FT-Transformer**（07, 比較用1本）: 表形式向け Transformer。XGBと同一プロトコルだが
  計算量の都合で**別フォールド（年次 2018–2025, Lag1）**で評価する参考値（§6, `transformer_vs_xgb.csv`）。
  最適化はせず「比較対象の一つ」として置く。

### 時間集約器の差し替え式化（`src/lib_temporal.py`）

時間方向の畳み込みをモデル本体から分離し、共通インターフェース
`forward(h_seq[L,N,hidden]) → h[N,hidden]` で差し替え可能にした:

- **GRUAggregator** … 系列をGRUに通し最終隠れ状態を町表現とする（**現行GRU挙動を完全維持**。
  パラメータ初期化順を旧実装に合わせ既知値を再現）。
- **AttentionAggregator** … L個の過去ステップへの softmax 重みを学習（加法注意）。集約表現に加え、
  学習した重み `[N, L]`（町ごとの過去四半期重み）を `last_weights` から取り出せる（重み可視化用）。
- **MeanAggregator / LastStepAggregator** … アブレーション用の単純基準（単純平均 / 直前1Qのみ）。

`SpatioTemporalGNN` は集約器を引数で受け取る（既定 `"gru"`）。`config.TEMPORAL_AGG` または
環境変数 `TEMPORAL_AGG` で切替。

## 6. 主要知見

数値は四半期アブレーション（`08q`, `ablation_loo_q.csv` / `ablation_forward_q.csv`, フルR²=0.569,
Central5=0.410）と64四半期モデル比較（`gnn_model_comparison.csv` 等）に基づく。
（参考: 年次アブレーション `ablation_loo.csv` はフルR²=0.500, Central5=0.309。）

**(a) ラグの寄与とST-lagの相補性**
- **Lag1 ≫ Lag2/3**: 直前ほど効く。05q で Qprev(直前1Q) 0.557 > Qyoy(前年同期) 0.531。
  LOOでも「直前1Q(T+S)除去 −0.043」≫「前年同期(T+S)除去 −0.016」。
- **S-lag の除去 ΔR²**: 全体 −0.049 / Central5 −0.078（四半期）。
  （年次では全体 **−0.063** / Central5 **−0.090** で、S-lagは都心ほど効く。）
- **S-lag + T-lag は相補的**: ラグを**同時に**全部抜くと −0.218（四半期）／**−0.194**（年次）で、
  個別除去の和（−0.049 + −0.027 ≈ −0.076）を大きく上回る。空間と時間は別々の情報を運ぶ。
- **冗長な特徴**: 用途地域 `Zoning` ΔR²≈ −0.0005、`Station_min`/`Station_TE` ともに ΔR²≈ −0.004。

**(b) 空間と時間の分解（Central5）**
- **グラフ伝播 ≒ 手作りS-lag**: `GNN-min`（静的GCN, 全体 0.562 / Central5 0.396）は
  `XGB-full`（手作りS-lag入り, 全体 0.569 / Central5 0.409）と**同等**。
  グラフ伝播が手作り近隣平均と同水準の空間情報を学べている。
- **ベースライン超えの上積みは「時間」由来**: `GNN-temporal`（GCN+GRU, 全体 0.587 / Central5 0.451）は
  静的GCNに **+0.025（全体）/ +0.055（Central5）** を上積み。上積みは **Central5 に集中**し、
  Others はベースラインとほぼ互角。直近性（時間方向）が都心の難しさを埋める。

**(c) FT-Transformer は XGB に劣後**
- 同一プロトコル（年次 2018–2025, Lag1）で XGB 0.522 vs Transformer 0.500（Central5 では 0.280 vs 0.239）。
  表形式・中規模データでは勾配ブースティングが強いという Zhan ら（香港）の知見が東京でも再現。

### モデル比較（全体R², 64四半期フォールド）

| モデル | 全体 R² | Central5 | Others | 位置づけ |
|--------|--------:|---------:|-------:|----------|
| OLS(Qboth) | 0.478 | 0.293 | 0.491 | 線形ベースライン |
| XGB-propT | 0.503 | — | — | 物件+自町T-lagのみ |
| GNN-min（静的GCN） | 0.562 | 0.396 | 0.585 | グラフ伝播 ≒ 手作りS-lag |
| XGB-full(Qboth) | 0.569 | 0.409 | 0.604 | 強いベースライン |
| GNN-temporal(GRU) | 0.587 | 0.451 | 0.603 | 時間で上積み（都心に集中） |
| GNN-temporal(Attention) | 0.589 | 0.459 | 0.601 | GRUと同等（集約器を注意に差替） |

（`run_compare.py` の時系列GNN行は XGB-full と同じ立地系特徴を物件ヘッドに入れた
公平比較設定（rich）で、GRU/Attention を同一特徴・同一フォールドで比較する。
集約器を GRU→Attention に差し替えても全体R²は 0.587→0.589 とほぼ不変。）

**(d) 時間Attentionの重みはほぼ一様（重み可視化, 12）**
- `AttentionAggregator`（過去Lステップへの softmax 重みを学習）の重み `[N,L]` を 64四半期
  ・40,709本（町×四半期）集計したところ、**ほぼ一様（≈1/8=0.125、一様からの総偏差 L1=0.003、
  最大重み 0.126）**。期待した「直近1Q(q−1)への集中」は**見られず**、都心5区も直近重視ではなく
  むしろ僅かに過去寄り（Central5 q−1=0.121 < Others 0.125）。図 `fig_attention_lags_full.png`。
- 解釈: 注意は GCN 符号化後の各時点表現に掛かるが、観測平米単価の**前方補完**で隣接四半期の
  表現が似るため、ステップ重み付けの自由度が乏しく softmax が一様化したと考えられる。
- 含意: GRU(0.587)→Attention(0.589) が同等で、かつ静的GCN(0.562)からの上積み(§6b)は
  **重み集中ではなく再帰・非線形性に由来**する可能性が高い。「直近性」は ST-lag（手作り）や
  GRU の構造に既に取り込まれており、明示的な時間注意で**追加抽出される余地は小さい**。

**(e) 空間×時間の 2×2 要因デザイン（因果推論的トグル, 16）**

「空間=近隣波及(graph)」×「時間=動態(temporal)」を、**1つのトグル以外を完全固定**した
2×2 で評価する（`16_factorial_2x2.py`, 全64四半期・学習窓12・seed 42/43/44 平均）。
4セル＝GCN/per-node Linear × GRU/LastStep。graph=off は GCNConv を、**近隣集約をしない
per-node Linear**（同 in→hidden・同2層・同 hidden・edge_index 不使用）に差し替えて実現し、
temporal=off は直前1ステップ(q−1)のみ＝時間集約なし。同一フォールドでは4セルが**同じ訓練/
テスト分割・同じ前処理（標準化/駅TE/one-hot/系列, フォールド内 fit）を共有**し、`lib_gnn.
assert_factorial_only_diff` が「差分は graph/temporal の2箇所だけ」を実行前に検証する。

| セル (graph,temporal) | 全体 R² | Central5 | Others |
|---|--:|--:|--:|
| GCN + GRU (on,on)        | 0.589 | 0.454 | 0.606 |
| GCN + LastStep (on,off)  | 0.581 | 0.440 | 0.598 |
| Linear + GRU (off,on)    | 0.584 | 0.446 | 0.600 |
| Linear + LastStep (off,off) | 0.568 | 0.411 | 0.587 |

要因分解（per-fold ペア差, n=64, Wilcoxon 符号順位 / 勝敗）:

| 効果 | 全体 | Central5 | Others |
|---|--:|--:|--:|
| 時間動態の主効果 | +0.012 (56/64, p<1e−9) | **+0.024 (56/64, p<1e−9)** | +0.011 (56/64) |
| 近隣波及の主効果 | +0.009 (55/64, p<1e−8) | +0.019 (53/64, p<1e−7) | +0.008 (55/64) |
| 交互作用 graph×temporal | −0.008 (負54/64, p<1e−8) | **−0.021 (負55/64, p<1e−9)** | −0.004 (負46/64) |

- **時間動態が主**：両因子とも正の主効果を持つが、時間動態 > 近隣波及で、差は Central5 で最大
  （+0.024 vs +0.019）。中心5区の難しさは主に**直近性（自町＋近隣の動態）**で埋まる。
- **近隣波及は中心5区の交互作用としては効かない**：事前に期待した「graph×temporal の正の
  交互作用」は**棄却**。交互作用は全 scope で**負**（劣加法的＝代替的）で、Central5 で最も強い
  （−0.021, 55/64 で負, p<1e−9）。temporal=off のとき近隣波及の上積みが大きく（0.411→0.440）、
  temporal=on だと縮む（0.446→0.454）。近隣波及と時間動態は**同じ「直近の価格水準」情報を
  別経路で取り込む代替**で、片方があれば他方の限界寄与は小さい。
- **留保（軸名の正確さ）**：ノード特徴に**自町の過去価格（前方補完平米単価）**を含むため、これは
  「近隣（隣接町）からのメッセージパッシングの有無」と「時間集約の有無」の分離であり、**純粋な
  空間/時間分離ではない**。graph=off でも各町は自分の過去価格を見ており、「自町の動態」は両 graph
  水準に残る。この事実を消すためにノード特徴を変えていない（軸名どおりに解釈する）。

## 7. 今後

- **時間Attention（検証済み・(d)）**: 学習された重みはほぼ一様で直近集中は観測されなかった。
  次は「観測フラグ自体への注意」や「価格そのもの（GCN前）への注意」で自由度を上げ、
  あるいは系列をダウンサンプリング（直近 vs 前年同期の2点）して重みの解釈性を高める。
- **受付帳の時間特徴統合**（季節・取引タイミング）。
- **GAT**（グラフ注意）でノード間の重みも学習し、queen隣接の等重み平均を超えられるか検証。
